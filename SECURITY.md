# SECURITY AND PRIVACY

HALO today is a published design — documents and templates, no
running code, no servers, no accounts, nothing that holds
anyone's data. This policy covers the repository, and it binds
every node that stands up under the design.

## Reporting a concern

If you find a security or privacy problem in this repository —
for example personal data committed by mistake, a credential in
any file or in the history, or a template that invites unsafe
disclosure — open an issue marked **security** (without the
sensitive content itself), or contact the repository's
maintainers through GitHub. Reports are read and acted on:
exposed material is removed and the exposure is disclosed in
the changelog.

## Rules for nodes and contributors

- **No personal data in the repository. Ever.** No names with
  addresses, no case files, no medical, financial, or legal
  records about identifiable people, no credentials or keys.
  If it was committed by mistake, report it as above — do not
  copy it further.
- **Aggregate and consent.** A node publishes community data in
  aggregate only, from public statistics or from data the
  community has consented to share, for the purposes the
  community agreed. Consent can be withdrawn; withdrawn data
  is removed from the node's publications.
- **Retention.** A node keeps only what its published work
  requires, and says in its node file what it keeps and for
  how long.
- **Simulations are not evidence about people.** A model
  output never names, scores, or judges an identifiable
  person. The system models allocations and structures —
  never individuals.
