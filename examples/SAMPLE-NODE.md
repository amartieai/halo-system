## One worked run — the minimal path, end to end

**Question (after the nine-judges gate):** *If the Trust funded
one thing first in Maple Junction, which of the five categories
returns the most stability per dollar over ten years?*

**Assumptions (all stated, all SAMPLE):**
- The allotment band is the one in DESIGN.md, applied to
  18,400 people.
- "Stability" = residents retained + households no longer in
  crisis spending, per the node's own definitions.
- Plant stays open for the run's horizon (a separate
  counterfactual run tests closure).

**Steps:**
1. Fill the node (above) from public statistics.
2. Grade the question through NINE-JUDGES.md; it passed on the
   second draft — the first draft asked three questions at once.
3. Run each category as its own scenario in the simulation
   guide's format; hold every other input constant.
4. Record outputs *as model outputs*, with the assumptions
   attached.

**Output (SAMPLE — a model's output, not a measurement):**
- Category 1 (seniors alone) ranked first on stability per
  dollar, driven by low per-household cost and high retention
  effect; category 3 (transit) ranked second and *first* on
  youth retention specifically. The node published both
  rankings, with the assumptions, and its community chose —
  the choice is the community's, the model only informs it.

**Limitations:** SAMPLE data proves nothing about any real
place. Even with real data: the model cannot establish what
*will* happen — only what follows from its inputs and rules.
Change the inputs, the answer may change; that sensitivity is
a result too, and gets published with the rest.
