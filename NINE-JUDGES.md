# THE NINE JUDGES — THE METHODOLOGY GATE

No question enters a HALO simulation raw. First it is graded.

The gate is a panel of **nine judges** — the Amarti judge tool's
methodology — applied to every question, scenario, and dataset a
community proposes to run. It exists for the same reason an audit
precedes a claim: an ungraded question produces an ungradeable
answer, and a simulation is only worth the discipline of its
inputs.

## What the gate checks

1. **Is the question stated so it can be false?** A scenario that
   cannot come out "no" is propaganda wearing a lab coat.
2. **Is the record identified?** The history, statistics, or
   documents the run will stand on are named, sourced, and their
   gaps declared (including gaps made by conquest or suppression).
3. **Are the adversarial inputs entered?** Controllers,
   manufactured fear, captured funds — present as modelled
   agents and flows, or their absence justified.
4. **Is the calibration stated?** Which layer decides what, which
   amounts are being found rather than asserted, what would make
   the operators re-run.
5. **Is the comparison honest?** Baseline and counterfactual
   differ in the named respect only; everything else is held.
6. **Can a stranger reproduce it?** Data in, settings written,
   results published — a run nobody can repeat is an anecdote.
7. **Whose choice is the outcome?** The run informs a community's
   decision; it does not replace it. Scenarios that smuggle in a
   ruler's decision wearing the people's clothes are returned.

## Verdicts

Each judge returns pass / fail with reasons, on the record. A
question needs the panel's pass to enter the shared library;
failed questions are published too, with the reasons — the
failures are calibration data for everyone else's gate.

## Lineage

The gate is the judging discipline of the Witness Stand project
(judging the judges: graded decisions, documented facts separated
from assertions, honest "not found" accepted as a completed
result) applied at the front door of every simulation.
